# Azeroth česky: Auctionator

Czech localization for Auctionator on WoW Forever 1.60.1. Adds Czech auction controls, shopping and selling text, lists, settings and help, with a bundled font supporting Czech characters.

**Website:** [azerothcesky.cz](https://azerothcesky.cz/)

## Instalace

Nainstaluj běžný Auctionator a vedle něj složku `AAzerothAuctionator` z tohoto ZIPu do `_classic_beta_/Interface/AddOns/`. Hru úplně restartuj. Čeština se použije automaticky; hlavní Azeroth česky není potřeba. Používej jen jeden překladový modul Auctionatoru současně.

**Web:** [azerothcesky.cz](https://azerothcesky.cz/)

Překlad se týká rozhraní Auctionatoru. Názvy předmětů a schopností dodané hrou zůstávají v originále, chybějící texty se zobrazí anglicky. Pro návrat k původnímu jazyku vypni tento doplněk a znovu načti rozhraní.
