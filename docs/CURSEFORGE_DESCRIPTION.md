# Azeroth česky: Auctionator

A standalone Czech translation for [Auctionator](https://www.curseforge.com/wow/addons/auctionator), maintained by the Azeroth česky project.

**Website:** [azerothcesky.cz](https://azerothcesky.cz/)

## Features

*   Czech translations for shopping, selling, cancelling auctions, shopping lists, settings and help text.
*   A bundled font with Czech characters for Auctionator's interface, including buttons and configuration tooltips.
*   Czech is selected automatically when this addon is enabled, independently of the game client's language.
*   Missing or newly added Auctionator translations fall back to English.

**Auctionator is required and must be installed separately. The main Azeroth česky addon is optional.** Item, spell and other names supplied by the game are outside this translation.

## Installation and compatibility

Install Auctionator and this addon alongside it, then restart the client. For manual installation, extract the installable ZIP into Interface/AddOns and keep the folder name **AAzerothAuctionator** unchanged.

Enable Auctionator and **Azeroth cesky: Auctionator**. Use only one Auctionator translation addon at a time. Disable this addon and reload the interface to return to the client language. When updating manually, replace the entire addon folder and restart the client.

The project is developed for **WoW: Forever**. Check the Files tab for supported game versions and the notes attached to each download.

## Česky

Samostatný český překlad Auctionatoru od projektu **Azeroth česky**. Překládá nákup, prodej, rušení aukcí, seznamy, nastavení a nápovědy. Obsahuje font s českou diakritikou.

**Web:** [azerothcesky.cz](https://azerothcesky.cz/)

**Vyžaduje samostatně nainstalovaný Auctionator. Hlavní Azeroth česky není potřeba.** Po zapnutí se čeština použije automaticky. Složku AAzerothAuctionator nepřejmenovávej a ostatní překladové moduly Auctionatoru nech vypnuté.

Projekt vzniká pro **WoW: Forever**. Podporované verze hry a poznámky k vydání najdeš u jednotlivých souborů. Při hlášení chyby přilož verzi klienta, obou addonů a snímek problematického místa.
